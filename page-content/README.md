# Starter text for your content pages

These are ready-to-paste drafts. In Shopify admin go to **Online Store → Pages → Add page**, paste the HTML into the content box (click the `<>` Show HTML button first), then add the page to your footer menu (**Online Store → Navigation → Footer**).

Replace everything in [square brackets] with your real details, and check that each statement is true for your business. This is general information, not legal advice; get your policies checked if you are unsure.
